# Grocery

Tool personale per generare la lista della spesa di un ciclo di **due settimane** a
partire dalla routine alimentare seguita, e spuntarla al supermercato dal telefono.

- Frontend statico (React + TypeScript + Vite), pensato per GitHub Pages.
- Configurazioni (cataloghi, stagionalità, routine) in JSON versionato: si aggiornano
  con un commit.
- Lista condivisa tra due persone, con accesso a passphrase.

📄 **La documentazione completa sta in [doc/](doc/README.md).**
❓ Le domande ancora aperte in [Q&A.md](Q&A.md).

## Sviluppo

```bash
npm install
npm run dev
npm test
```
